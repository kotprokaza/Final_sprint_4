# Автоматизированное тестирование для сервиса "Яндекс Самокат"

Этот проект содержит автоматизированные тесты для веб-сервиса аренды самокатов "Яндекс Самокат".

## 🚀 Возможности

- **Кросс-браузерное тестирование** - поддержка Chrome и Firefox
- **Параметризованные тесты** - запуск тестов с разными наборами данных
- **Автоматическая настройка драйверов** - через WebDriverManager
- **Maven управление** - удобный запуск через профили

## 🛠 Технологии

- **Java 11**
- **JUnit 4** - фреймворк для тестирования
- **Selenium WebDriver** - автоматизация браузера
- **WebDriverManager** - автоматическое управление драйверами
- **Maven** - управление зависимостями и сборка

## ⚙️ Настройка и запуск

### Предварительные требования

- Java 11 или выше
- Maven 3.6 или выше
- Доступ к интернету (для загрузки зависимостей и драйверов)

### Запуск тестов

#### Все тесты в обоих браузерах
```bash
mvn test -Pchrome && mvn test -Pfirefox
Только Chrome
bash
mvn test -Pchrome
Только Firefox
bash
mvn test -Pfirefox
Конкретный тестовый класс
bash
mvn test -Pchrome -Dtest=OrderTest
mvn test -Pfirefox -Dtest=FAQTest
Отладочный тест для Firefox
bash
mvn test -Pfirefox -Dtest=FirefoxDebugTest
Использование скрипта для запуска
Также доступен скрипт для удобного запуска:

bash
./run_tests.sh

Используйте Page Object паттерн

Реализуйте методы для взаимодействия с элементами страницы

Для отладки проблем с Firefox используйте:

bash

Этот тест предоставляет детальную информацию о состоянии элементов и ошибках.
