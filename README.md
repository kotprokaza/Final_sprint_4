# Sprint 4: Autotests for Яндекс Самокат

Проект содержит автоматизированные тесты для учебного сервиса Яндекс Самокат.

## 📋 Описание проекта

Проект включает в себя автоматизированные тесты на Selenium WebDriver для проверки функциональности сервиса Яндекс Самокат:
- Тестирование оформления заказа через разные кнопки
- Тестирование раздела "Вопросы о важном" (FAQ)
- Параметризованные тесты с использованием JUnit 4

## 🚀 Запуск тестов

### Запуск всех тестов
```bash
mvn clean test
Запуск конкретного тестового класса
bash
mvn test -Dtest=tests.OrderTest
mvn test -Dtest=tests.FAQTest
Запуск с подробным выводом
bash
mvn test -e
📊 Тестовые сценарии
OrderTest
testOrderScooter - проверка оформления заказа через верхнюю и нижнюю кнопки

Параметризованный тест с двумя наборами данных

FAQTest
testFAQItem - проверка выпадающего списка в разделе "Вопросы о важном"

Параметризованный тест для 8 вопросов

🎯 Особенности реализации
Page Object Pattern - разделение логики тестов и работы с элементами

Параметризация - использование JUnit Parameterized для многократного запуска тестов

WebDriverManager - автоматическое управление драйверами браузеров

Явные ожидания - использование WebDriverWait для стабильности тестов

📝 Требования
Проект соответствует следующим требованиям:

✅ В классах с тестами лежат только тесты

✅ Методы работы с веб-элементами и локаторы хранятся в Page Object классах

✅ Написаны два теста на заказ самоката (верхняя/нижняя кнопки)

✅ Написаны FAQ тесты с параметризацией

✅ Проект загружен на GitHub с правильной структурой веток
